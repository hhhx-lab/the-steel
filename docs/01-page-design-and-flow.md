# 01 页面设计与整体流转

本文档描述铁子 MVP 第一阶段前端的页面组成、页面职责、展示信息和页面之间的跳转关系。目标读者是前端开发、产品、设计和后续接手的 AI 编程 Agent。

## 1. 产品主线

铁子第一阶段是一个移动端优先的 React PWA，核心体验围绕健身房现场使用：

```text
打开 App
↓
跳过复杂建档
↓
拍一下器械
↓
识别器械
↓
看小白教程
↓
加入今日训练
↓
完成动作
↓
基础记录
```

第一阶段页面不做社区、饮食、私教交易、复杂建档和视频姿态纠错，所有页面都服务于“拍一下器械，小铁带你练”的闭环。

## 2. 页面清单

| 页面 | 路由 | 优先级 | 当前实现文件 | 页面职责 |
|---|---|---|---|---|
| 欢迎页 | `/welcome` | P0 | `src/pages/WelcomePage.tsx` | 新用户第一屏，解释产品价值，直接进入拍器械或今日训练 |
| 首页 / 今日训练 | `/home` | P0 | `src/pages/HomePage.tsx` | 展示默认新手训练计划和核心快捷入口 |
| 拍器械页 | `/scan` | P0 | `src/pages/ScanPage.tsx` | 相机、相册上传、识别中、mock 识别场景 |
| 识别结果页 | `/scan/result` | P0 | `src/pages/ScanResultPage.tsx` | 展示器械识别结果、置信度、今日训练建议和下一步 |
| 动作教程页 | `/exercise/:exerciseId` | P0 | `src/pages/ExercisePage.tsx` | 展示小白动作教程，包括练哪里、怎么调、怎么做和安全提醒 |
| 训练中页 | `/workout/session` | P0 | `src/pages/WorkoutSessionPage.tsx` | 展示训练进度、动作 checklist、当前动作和记录入口 |
| 记录确认页 | `/workout/log` | P0 | `src/pages/WorkoutLogPage.tsx` | 支持手动记录和一句话记录，AI 解析后确认保存 |
| 我的页 | `/profile` | P1 | `src/pages/ProfilePage.tsx` | 简版设置、昵称、隐私说明、本地数据清除 |

## 3. 底部导航

底部导航由 `src/components/layout/BottomNav.tsx` 实现，仅在常规主页面展示。

| Tab | 路由 | 设计意图 |
|---|---|---|
| 今日 | `/home` | 回到今日训练和快捷入口 |
| 拍器械 | `/scan` | 核心功能入口，居中并使用高对比样式 |
| 我的 | `/profile` | 本地设置和隐私说明 |

欢迎页、扫描页、识别结果页、教程页、训练中页和记录页使用沉浸式页面，不显示底部导航，避免训练现场操作被打断。

## 4. 首次进入流转

首次打开时，根路由 `/` 根据 `userStore.hasVisited` 判断是否进入欢迎页。

```text
/
↓ hasVisited = false
/welcome
↓ 点击「拍一下器械」
设置 hasVisited = true
/scan
```

另一个入口：

```text
/welcome
↓ 点击「先看看训练计划」
设置 hasVisited = true
/home
```

欢迎页必须传达的信息：

- 产品名：铁子
- AI 陪练名：小铁
- 主张：不认识器械，也能开始练
- 低门槛：不强制上传体态照片
- 主入口：拍一下器械

## 5. 首页流转

首页是非首次用户默认入口。

```text
/home
├── 点击「开始训练」→ /workout/session
├── 点击「拍一下器械」→ /scan
├── 点击「一句话记录」→ /workout/log
└── 点击「新手指南」→ 首页弹层
```

首页展示信息：

- 小铁问候
- 今日训练卡片
- 训练时长
- 动作数量
- 已保存记录数量
- 默认动作清单
- 快捷入口：拍器械、一句话记录、新手指南
- 小铁训练提示

首页不做：

- 社区 feed
- 饮食信息
- 复杂数据仪表盘
- 私教销售入口

## 6. 拍器械流转

拍器械页是 MVP 最核心入口。

```text
/scan
↓ 打开相机或选择相册
获取图片
↓
识别中 recognizing
↓
/scan/result
```

当前实现支持三种 mock 场景：

| 场景 | 按钮 | 结果 |
|---|---|---|
| 高置信度 | 高置信度 | 高位下拉器，confidence = 0.92 |
| 中置信度 | 可能是 | 坐姿划船器，confidence = 0.72 |
| 低置信度 | 需补拍 | unknown，confidence = 0.48 |

拍摄页展示信息：

- 相机取景区
- 构图辅助框
- 拍摄引导文案
- 相册入口
- 补光占位
- mock 场景按钮
- 小铁提示

## 7. 识别结果流转

识别结果页根据置信度改变展示。

```text
/scan/result
├── confidence >= 0.80 → 展示确定结果
├── 0.65 <= confidence < 0.80 → 展示「可能是」，要求用户确认
└── confidence < 0.65 → 不展示确定结论，提示补拍
```

高置信度或中置信度时：

```text
/scan/result
├── 点击「看怎么用」→ /exercise/:exerciseId
├── 点击「加入今日训练」→ /workout/session
├── 点击「重新识别」→ /scan
└── 点击「识别不准？」→ 反馈弹层
```

低置信度时：

```text
/scan/result
↓ 展示补拍提示
点击「重新拍」
/scan
```

识别结果页展示信息：

- 识别置信度
- 器械名称
- 小白解释
- 训练部位
- 专业肌群
- 是否适合新手
- 风险等级
- 今日训练建议
- 小铁重量策略提示

## 8. 动作教程流转

动作教程页从识别结果页或训练中页进入。

```text
/exercise/:exerciseId
├── 点击「加入今日训练」→ 留在当前页，更新训练计划
└── 点击「开始训练」→ /workout/session
```

动作教程页展示信息：

- 动作名称
- 动作小白解释
- 示意画面占位
- 练哪里
- 怎么调
- 怎么做
- 常见错误
- 安全提醒
- 底部固定操作区

## 9. 训练中流转

训练中页承接默认计划和识别后加入的动作。

```text
/workout/session
├── 点击 checklist 动作 → 切换当前动作
├── 点击「查看教程」→ /exercise/:exerciseId
├── 点击「记录这一组」→ /workout/log?exerciseId=xxx
├── 点击「完成当前动作」→ 当前动作 completed，切换下一个动作
└── 点击「结束」→ 结束确认弹层
```

训练中页展示信息：

- 训练进度
- 动作 checklist
- 当前动作名称
- 小白解释
- 建议组数
- 建议次数
- 已记录条数
- 重量策略
- 查看教程入口
- 记录入口
- 完成当前动作按钮
- 小铁安全提示

## 10. 记录流转

记录页支持两种模式。

手动记录：

```text
/workout/log
↓ 选择「手动记录」
填写组数 / 重量 / 次数 / 感受 / 备注
↓
保存记录
/workout/session
```

一句话记录：

```text
/workout/log
↓ 选择「一句话」
输入自然语言
↓ 点击「解析这句话」
mock parseWorkoutLog
↓
展示可编辑解析结果
↓ 点击「确认并保存」
saveWorkoutLog
↓
/workout/session
```

记录页必须保证：

- AI 解析结果必须给用户确认
- 用户可以修改重量和次数
- 疼痛、不适、旧伤关键词触发安全提示
- 保存后返回训练中页

## 11. 我的页流转

```text
/profile
├── 修改昵称 → 本地保存
├── 清除本地数据 → 确认弹层 → /welcome
└── 查看隐私说明 → 留在当前页
```

我的页第一阶段只承载基础设置，不承载账号体系、订阅、社区和复杂隐私中心。

## 12. 全局跳转原则

- 主流程优先短链路，避免用户在健身房现场迷路。
- 训练现场相关页面不展示底部导航，减少误触。
- 所有关键动作都有明确下一步：看教程、加入训练、开始训练、记录。
- 低置信度不允许假装确定，必须引导补拍。
- 疼痛和旧伤相关信息必须优先显示安全提示。
